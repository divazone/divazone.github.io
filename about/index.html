關於我

簡介

現任 Chunghwa Telecom Co., Ltd. 雲端解決方案架構師，主要專注於 Microsoft Azure、Amazon Web Services（AWS）、雲端基礎架構與系統整合。擁有超過 8 年的 IT 基礎架構設計與實務經驗，長期投入 Linux、網路、虛擬化、混合雲與公有雲相關技術。

在技術發展的過程中，持續拆解不同世代的 IT 架構，從傳統資料中心、Linux 與網路基礎設施，一路延伸至 Azure、AWS 與 Cloud Native 生態系，嘗試在傳統基礎設施、開源技術與公有雲之間找到合適的整合方式，並將新的技術轉化為能實際解決問題的架構與工具。

曾任職於國家高速網路與計算中心（NCHC）擔任系統工程師，累積 Linux、網路、混合雲及開源技術相關經驗。

這個 Blog 主要記錄我在雲端運算、IT 基礎架構、Linux、開源技術與 Cloud Native 領域的學習筆記與實務經驗，偶爾也寫寫哩程、飛行與旅遊的生活紀錄。
